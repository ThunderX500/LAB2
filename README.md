## How to Run

### Run the Application
Start the local development server:
```bash
./gradlew bootRun
```
*Open [http://localhost:8080/](http://localhost:8080/) in your browser to view the app.*

### Run the Tests
Execute the unit tests (test report output is found in './build/reports/tests/test/index.html'):
```bash
./gradlew test
```
